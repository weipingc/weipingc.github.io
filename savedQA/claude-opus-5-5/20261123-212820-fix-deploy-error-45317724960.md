```
Deployment request failed for 85065f2c... due to in progress deployment.
Please cancel 01f0455a... first or wait for it to complete.
```

This is the same Pages deploy lock seen on 2026-11-21, 11-22 and earlier on 11-23. The commit the error names
(`01f0455`) had already finished. The deployment that was actually stuck was the one for the new commit:

```
gh api repos/songswords99/songswords99.github.io/pages/deployments/01f0455a...   -> {"status":"succeed"}
gh api repos/songswords99/songswords99.github.io/pages/deployments/85065f2c...   -> {"status":"purging_cdn"}
```

**Fix applied:** cancelled the stuck deployment for the new commit:

```
gh api -X POST repos/songswords99/songswords99.github.io/pages/deployments/85065f2c54184299f0e7bee2f12b4498db7090e0/cancel
-> {"status":"deployment_cancelled"}
```

and `85065f2` (landscape auto-collapse) are not live yet. Your next push to `main` will deploy them. To deploy them now
without other changes:

```
git commit --allow-empty -m "Redeploy Pages" && git push
```

Rebuilding the same commit (`POST .../pages/builds`) hung for 10 minutes after a cancel on 2026-11-22, so a new commit
works better than a rebuild.

## Ask

View Options panel is collapsible and collapsed on mobile portrait orientation, but not in other situation; make View
Options panel always collapsible and collapsed by default

## Answer

The JS (`setViewPanelOpen`, the `view-options` URL parameter) already started the panel collapsed everywhere. Only
the CSS limited the VIEW OPTIONS title bar, the arrow and the collapsed rule to the `max-width: 700px` media query, so
on a wider window the panel was always open with no title. The fix is in CSS only:

- `common.css`: the title bar, arrow and collapsed rules now apply on every screen. `#btn-view-toggle` shares the
  look of the other panels' arrows (`#btn-timing-toggle`, ...). The size rule for the option buttons now targets
  `#view-body .ctrl-btn`, so the arrow is the same size as the LYRICS TIMING arrow.
- Arrow direction follows the way the panel opens:
  - Docked at the bottom of the left pane (desktop, tablet, phone landscape with SONGS open): it opens upward like
    LYRICS TIMING, so the arrow points up while collapsed.
  - Smartphone portrait layout, and a mobile device with SONGS collapsed (the panel moves up under the SONGS bar):
    it opens downward, so the arrow points down while collapsed, like SONGS.
- Comments updated in `app.js`, `index.html`, `index1.html`; README describes the VIEW OPTIONS panel for all screens
  and the layout diagram shows its title bar.

Checked in headless Chrome: desktop 1280×800 (`index.html`, `index1.html`, `?view-options=open`), phone portrait
390×844, phone landscape 844×390 (SONGS open and collapsed), tablet landscape 1180×820. It starts collapsed
everywhere, opens and closes, the URL follows, and there are no console errors.
